# Clavia Nord C2D (2012-)

Dual-manual combo organ from [[clavia|Clavia]] Nord C Series — known for **button drawbars** instead of sliders: a row of buttons lights up LEDs to show the current drawbar setting, in place of the nine physical sliders a real B-3 uses.^[raw/articles/wikipedia-clonewheel-organ.md]

## Position in the Nord family
- **Nord Electro** series (2001-) — stage keyboard with organ section.
- **Nord Stage** series (2005-) — adds piano and synth sections.
- **Nord C1 / C2 / C2D** (2007-) — the dedicated combo-organ line.
- **Nord Pedal Key 27** — MIDI pedalboard companion.^[raw/articles/wikipedia-clonewheel-organ.md]

The button-drawbar approach keeps the visual footprint of the organ compact, useful for stage players who want a real B-3 patch UI without giving up keyboard real estate.
