# Roland VK-7 (1997)

Dual-manual virtual-modeling clonewheel from [Roland](/entities/manufacturers/roland-corporation.md) — one of the first major DSP-emulated Hammonds to put a **wooden case** around the electronics, a deliberate nod to the B-3 heritage.[1]

## Position in the Roland family
- **VK-1** (1980) — early analog clonewheel, the first Roland attempt.
- **VK-7** (1997) — virtual modeling, wooden case.
- **VK-8 / VK-8m / VK-88 / VK-9 / VK-6 / VK-09** (2002+) — iterative updates in the same lineage.
- **VR-760 / VR-730 / VR-09** (V-Combo) — combo-keyboard spin-off.
- **Atelier AT-900 / AT-900c / AT-800** — organ variant.[1]
